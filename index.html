Make a set of XRP chips

One main wallet funds three chips. Each chip gets its own small wallet holding exactly its value, its own passphrase, and its own NFC link, so each one can be claimed once and can never touch the others. Keys are created and encrypted on this device.

4Write the card and passphrases

Each chip needs its own passphrase. Anyone who copies a tag could try guessing its passphrase offline, so a three or four word phrase is far safer than a short PIN.

This page's web address. On GitHub Pages it fills itself in.

5Write each tag

  1. In NFC Tools, choose Write, add a URL record, and paste one chip's link. Write it to that chip's tag.
  2. Label the tags as you go so each link ends up in the chip with the matching value.
  3. Tap each chip to test it, then use Other → Lock tag. Locking is permanent.
