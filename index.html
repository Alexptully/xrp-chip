I have a gift code to open

1Create the wallet

Write this key down and keep it until your friend has claimed the gift. If the chip is lost or the passphrase forgotten, this is the only way to recover the funds.

2Fund it from Robinhood

The wallet needs at least 2.1 XRP for your friend to receive a full 1 XRP in Robinhood. The first 1 XRP stays locked as the ledger's reserve and can't be sent. If Robinhood asks for a destination tag when you send, pick the option for no tag; a personal wallet doesn't use one.

View on xrpscan.com

3Write the card and set a passphrase

Someone who copies the tag could try guessing the passphrase offline. A 4-digit PIN falls in minutes; a three or four word phrase is out of reach. For a few dollars either is fine, just know the trade.

This page's web address. On GitHub Pages it fills itself in; only change it if you move the page.

4Write it to the tag

  1. In NFC Tools (iOS or Android), choose Write, add a URL record, and paste the chip link.
  2. Write it to the tag, then tap the tag with a phone to test that the gift page opens and the passphrase works.
  3. Once it works, use Other → Lock tag so nobody can overwrite it. Locking is permanent.
